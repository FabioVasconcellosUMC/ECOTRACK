# EcoTrack Frontend

Frontend oficial do EcoTrack, desenvolvido com Vue.js, Tailwind CSS, Axios, Chart.js e Vite.

## Project setup

```sh
npm install
```

## Desenvolvimento

```sh
npm run dev
```

Para apontar para outra API, configure a variavel:

```text
VITE_API_BASE_URL=https://sua-api.exemplo.com
```

Sem essa variavel, o frontend usa a API publicada no Render.

## Build de producao

```sh
npm run build
```

## Preview local

```sh
npm run preview
```
